# 05 — 配置与设置

插件有两套配置文件，以及两类运行时持久状态：

| 机制 | 用途 | 读取方式 |
|------|------|----------|
| `_conf_schema.json` | 定义插件配置项、类型和默认值 | `hostApi.getSettings()` |
| `schemas/settings-schema.json` | 定义宿主设置 UI | 宿主自动读取并渲染 |
| `hostApi.storage.plugin` | 插件级持久状态 | Host API |
| `hostApi.storage.session` | 当前会话级持久状态 | Host API |

配置适合用户可见、可编辑的选项；storage 适合插件运行过程中产生的状态。

## _conf_schema.json

每个键就是一个配置项：

```json
{
  "greeting_prefix": {
    "type": "string",
    "description": "问候语前缀",
    "hint": "命令回复时显示在名字前面的文本",
    "default": "你好",
    "section": "general"
  },
  "enable_echo": {
    "type": "bool",
    "description": "启用复读功能",
    "hint": "开启后正则匹配到的消息会被原样复读",
    "default": true,
    "section": "general"
  },
  "max_retries": {
    "type": "number",
    "description": "最大重试次数",
    "hint": "失败后自动重试的最大次数",
    "default": 3,
    "section": "advanced"
  },
  "llm_footer": {
    "type": "text",
    "description": "LLM 回复后缀",
    "hint": "追加到每条 LLM 回复末尾的文本，留空则不追加",
    "default": "",
    "section": "advanced"
  }
}
```

字段说明：

| 字段 | 类型 | 说明 |
|------|------|------|
| `type` | string | 配置值类型 |
| `description` | string | 配置项简述 |
| `hint` | string | 更详细提示 |
| `default` | any | 默认值 |
| `section` | string | 分组标识 |

支持的 `type`：

| type | 说明 | 默认值类型 |
|------|------|-----------|
| `string` | 单行文本 | string |
| `text` | 多行文本 | string |
| `bool` | 布尔开关 | boolean |
| `int` | 整数 | number |
| `float` | 浮点数 | number |
| `number` | 浮点数，推荐使用 | number |

## 在代码中读取配置

```javascript
const settings = hostApi.getSettings() || {};

const prefix = settings.greeting_prefix ?? "你好";
const enabled = settings.enable_echo ?? true;
const retries = settings.max_retries ?? 3;
```

等价读取方法：

- `hostApi.getSettings()`
- `hostApi.readSettings()`
- `hostApi.getPluginSettings()`
- `hostApi.getConfig()`

首次运行时用户可能尚未保存配置，返回值可能是 `{}`。始终用 `??` 或 `||` 提供默认值。

## schemas/settings-schema.json

设置 schema 控制宿主 App 中“插件设置”页面的 UI，不影响配置读取逻辑。

```json
{
  "title": "Hello World 设置",
  "sections": [
    {
      "sectionId": "general",
      "title": "基础设置",
      "fields": [
        {
          "fieldType": "text_input",
          "fieldId": "greeting_prefix",
          "label": "问候语前缀",
          "placeholder": "例如：你好",
          "defaultValue": "你好"
        },
        {
          "fieldType": "toggle",
          "fieldId": "enable_echo",
          "label": "启用复读功能",
          "defaultValue": true
        },
        {
          "fieldType": "select",
          "fieldId": "mode",
          "label": "工作模式",
          "defaultValue": "auto",
          "options": [
            { "value": "auto", "label": "自动" },
            { "value": "manual", "label": "手动" }
          ]
        }
      ]
    }
  ]
}
```

顶层字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `title` | string | 设置页面标题 |
| `sections` | array | 分组列表 |

section 字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `sectionId` | string | 分组 ID |
| `title` | string | 分组标题 |
| `fields` | array | 字段列表 |

field 字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `fieldType` | string | 控件类型 |
| `fieldId` | string | 字段 ID，应与 `_conf_schema.json` key 对应 |
| `label` | string | 显示标签 |
| `placeholder` | string | 占位文本，仅 `text_input` |
| `defaultValue` | any | UI 默认值 |
| `options` | array | 选项，仅 `select` |

支持的 `fieldType`：

| fieldType | 渲染为 | `defaultValue` 类型 |
|-----------|--------|---------------------|
| `toggle` | 开关 | boolean |
| `text_input` | 文本输入框 | string |
| `select` | 下拉选择 | string |

## 配置与设置 UI 的关系

- `_conf_schema.json` 定义数据：有哪些配置项、类型和默认值。
- `settings-schema.json` 定义 UI：宿主如何渲染设置界面。
- `fieldId` 应与 `_conf_schema.json` 的 key 一致。
- 只有 `_conf_schema.json` 时插件仍可读取配置，但没有设置 UI。
- 只有 `settings-schema.json` 时宿主会渲染 UI，但插件仍需要自行处理缺省值。

如果插件配置 key 与宿主核心设置 key 重叠，宿主可能将该字段归入核心设置存储，避免在插件配置页重复展示。普通插件不应主动复用宿主核心设置 key，除非明确知道该 key 的含义。

## 运行时持久状态

插件级状态：

```javascript
hostApi.storage.plugin.set("seen:user-1", true);
const seen = hostApi.storage.plugin.get("seen:user-1", false);
const keys = hostApi.storage.plugin.keys("seen:");
hostApi.storage.plugin.remove("seen:user-1");
```

会话级状态：

```javascript
hostApi.storage.session.set("last-command", "ping");
const last = hostApi.storage.session.get("last-command", "");
```

限制：

- key trim 后不能为空，最长 128 字符。
- value 必须是 JSON 可序列化值。
- 单值大小受宿主持久层限制，建议控制在 64 KB 以内。
- `storage.session` 需要当前消息会话上下文；插件启动阶段没有会话时不可用。

不要把密钥、Token、数据库连接信息或大型缓存写入插件状态。
