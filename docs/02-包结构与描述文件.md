# 02 — 包结构与描述文件

## 目录布局

```text
plugin-root/
├── manifest.json              # 必需：插件身份、版本、权限
├── android-plugin.json        # 必需：运行时、配置入口、网络白名单
├── _conf_schema.json          # 可选：静态配置定义
├── runtime/
│   ├── bootstrap.js           # 必需：QuickJS 入口
│   └── utils.js               # 可选：ES module 辅助文件
├── schemas/
│   └── settings-schema.json   # 可选：设置 UI schema
└── assets/                    # 可选：图片、音频、静态文件
```

规则：

- `manifest.json` 与 `android-plugin.json` 必须在插件根目录。
- `runtime.bootstrap` 必须是插件根目录下、位于 `runtime/` 内的相对路径。
- JS 文件只能使用 ES Module 语法。
- 不支持 CommonJS、Node.js 内置模块和宿主源码导入。

## manifest.json

```json
{
  "pluginId": "com.example.helloworld",
  "version": "1.0.0",
  "protocolVersion": 2,
  "author": "Your Name",
  "title": "Hello World 示例插件",
  "description": "最小可导入、可执行、可配置的 ElymBot 插件模板",
  "permissions": [],
  "minHostVersion": "0.4.0",
  "maxHostVersion": "",
  "sourceType": "LOCAL_FILE",
  "entrySummary": "演示命令处理、正则匹配、LLM 钩子和配置读取",
  "riskLevel": "LOW"
}
```

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `pluginId` | string | 是 | 全局唯一标识，推荐反向域名 |
| `version` | string | 是 | 语义版本号 |
| `protocolVersion` | number | 是 | 固定为 `2` |
| `author` | string | 是 | 作者名 |
| `title` | string | 是 | 显示名称 |
| `description` | string | 是 | 一句话描述 |
| `permissions` | array | 是 | 权限声明数组，可为空但字段不能缺失 |
| `minHostVersion` | string | 是 | 支持的最低宿主版本 |
| `maxHostVersion` | string | 否 | 留空表示不限 |
| `sourceType` | string | 是 | 通常为 `"LOCAL_FILE"` 或 `"GIT"` |
| `entrySummary` | string | 是 | 功能概要 |
| `riskLevel` | string | 否 | `"LOW"` / `"MEDIUM"` / `"HIGH"` |

### permissions

`permissions` 中每一项是对象：

```json
{
  "permissionId": "network_request",
  "title": "网络请求",
  "description": "允许插件通过宿主代理访问白名单域名",
  "riskLevel": "MEDIUM",
  "required": true
}
```

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `permissionId` | string | 是 | 见 [07-权限与安全边界](07-权限与安全边界.md) |
| `title` | string | 是 | 展示给用户的权限标题 |
| `description` | string | 是 | 展示给用户的权限说明 |
| `riskLevel` | string | 否 | 默认 `"MEDIUM"` |
| `required` | boolean | 否 | 默认 `true` |

只有声明、用户授权、触发上下文允许三者同时满足时，受控 Host API 才会执行。

## android-plugin.json

```json
{
  "protocolVersion": 2,
  "runtime": {
    "kind": "js_quickjs",
    "bootstrap": "runtime/bootstrap.js",
    "apiVersion": 1
  },
  "config": {
    "staticSchema": "_conf_schema.json",
    "settingsSchema": "schemas/settings-schema.json"
  },
  "network": {
    "allowedDomains": ["api.example.com", "cdn.example.com"]
  }
}
```

| 字段 | 说明 |
|------|------|
| `protocolVersion` | 固定为 `2` |
| `runtime.kind` | 固定为 `"js_quickjs"` |
| `runtime.bootstrap` | 相对插件根目录，必须位于 `runtime/` 下 |
| `runtime.apiVersion` | 当前为 `1` |
| `config.staticSchema` | `_conf_schema.json` 路径，留空表示无静态配置 |
| `config.settingsSchema` | 设置 UI schema 路径，留空表示无设置界面 |
| `network.allowedDomains` | Host API 网络请求允许访问的裸域名列表 |

`network.allowedDomains` 规则：

- 只能写裸域名，例如 `api.example.com`。
- 不要写 `https://api.example.com`、`api.example.com/path`、`api.example.com:443`。
- 子域名按后缀匹配：允许 `example.com` 会允许 `api.example.com`。
- `localhost`、私有网段、`.local`、`.internal`、`.lan` 等本地目标会被宿主拦截。

## 模块系统

```javascript
// runtime/utils.js
export function greet(name) {
  return `你好，${name}！`;
}

// runtime/bootstrap.js
import { greet } from "./utils.js";

export default async function bootstrap(hostApi) {
  hostApi.registerCommandHandler({
    key: "example.greet",
    command: "greet",
    handler(event) {
      event.replyText(greet(event.remainingText || "世界"));
    },
  });
}
```

支持相对导入 `./utils.js` 或 `./sub/module.js`，路径相对于当前 JS 文件。不要导入插件根目录外文件。

## 打包注意

- ZIP 根层应直接包含 `manifest.json` 和 `android-plugin.json`，不要多包一层父目录。
- 不要包含 `runtime/workspace` 或运行时临时内容。
- 路径必须使用 `/`，不能使用 Windows 反斜杠。
- 包内路径不能包含 `.`、`..`、绝对路径或盘符。
