# 04 — 处理器与钩子

所有处理器都在 `bootstrap(hostApi)` 中注册。注册阶段只声明能力，真正业务逻辑在宿主触发对应事件时执行。

## 通用注册字段

消息、命令、正则处理器共享这些字段：

```javascript
{
  key: "my-plugin.unique-key",
  registrationKey: "my-plugin.unique-key",
  priority: 0,
  metadata: {},
  declaredFilters: [],
  filters: {},
  handler(event) {}
}
```

说明：

- `key` 与 `registrationKey` 等价，推荐使用 `key`。
- `priority` 数字越小越先执行，默认 `0`。
- `metadata` 只做诊断信息，不参与业务逻辑。
- `declaredFilters` 是兼容旧写法；`filters` 是新组合表达式。二者不能同时出现。
- `filters` / `declaredFilters` 只允许用于 message / command / regex 注册。

## 命令处理器

```javascript
hostApi.registerCommandHandler({
  key: "my-plugin.greet",
  command: "hello",
  aliases: ["hi"],
  groupPath: [],
  priority: 0,
  filters: {
    anyOf: [
      { eventMessageType: "group" },
      { platformAdapterType: "onebot" }
    ]
  },
  metadata: {
    description: "打招呼命令"
  },
  handler(event) {
    event.replyText(`你好，${event.remainingText || "世界"}`);
  },
});
```

命令事件字段：

| 属性 | 类型 | 说明 |
|------|------|------|
| `eventId` | string | 事件 ID |
| `platformAdapterType` | string | 平台类型，如 `app_chat`、`qq`、`onebot` |
| `messageType` | string | 消息类型 |
| `conversationId` | string | 当前会话 ID |
| `senderId` | string | 发送者 ID |
| `timestampEpochMillis` | number | 时间戳 |
| `rawText` | string | 原始文本 |
| `workingText` | string | 宿主预处理后的文本 |
| `normalizedMentions` | string[] | 标准化 @ 列表 |
| `extras` | object | 宿主附加信息 |
| `stage` | string | `Command` |
| `commandPath` | string[] | 匹配到的命令路径 |
| `args` | string[] | 参数数组 |
| `matchedAlias` | string | 实际匹配的命令名或别名 |
| `remainingText` | string | 命令后剩余文本 |
| `invocationText` | string | 完整触发文本 |

命令事件方法：

| 方法 | 说明 |
|------|------|
| `event.replyResult(payload)` | 结构化回复 |
| `event.replyText(text)` | 纯文本回复 |
| `event.stopPropagation()` | 阻止后续处理器 |

等价别名：`sendResult` / `reply` / `respond` 等价于 `replyResult`；`sendText` / `respondText` 等价于 `replyText`。

`replyResult` 支持字符串或对象：

```javascript
event.replyResult({
  text: "这是回复文本",
  attachments: [
    {
      source: "assets/photo.jpg",
      mimeType: "image/jpeg",
      label: "照片"
    }
  ]
});
```

## 消息处理器

消息处理器在命令匹配前触发，可用于观察、预处理或截断传播。

```javascript
hostApi.registerMessageHandler({
  key: "my-plugin.msg-logger",
  priority: 0,
  filters: { eventMessageType: "group" },
  handler(event) {
    hostApi.log("INFO", `收到消息：${event.rawText}`);
  },
});
```

消息事件字段与命令事件的公共字段一致，但没有 `args`、`commandPath`、`remainingText` 等命令专属字段。`stage` 为 `AdapterMessage`。

方法：

- `event.stopPropagation()`：阻止后续消息处理器和命令匹配。

## 正则处理器

```javascript
hostApi.registerRegexHandler({
  key: "my-plugin.echo",
  pattern: "^echo[：:]\\s*(.+)",
  flags: ["i"],
  priority: 0,
  handler(event) {
    const captured = event.groups[0];
    event.stopPropagation();
    hostApi.log("INFO", `匹配到：${captured}`);
  },
});
```

正则事件额外字段：

| 属性 | 类型 | 说明 |
|------|------|------|
| `patternKey` | string | 匹配到的注册 key |
| `matchedText` | string | 完整匹配文本 |
| `groups` | string[] | 捕获组数组 |
| `namedGroups` | object | 命名捕获组 |

## 过滤器

### 组合表达式

`filters` 支持 `allOf`、`anyOf`、`not`：

```javascript
filters: {
  allOf: [
    { eventMessageType: "group" },
    {
      anyOf: [
        { platformAdapterType: "onebot" },
        { platformAdapterType: "qq" }
      ]
    },
    { not: { permissionType: "blocked" } }
  ]
}
```

内置条件：

| 字段 | 说明 |
|------|------|
| `eventMessageType` | 匹配事件消息类型 |
| `platformAdapterType` | 匹配平台类型 |
| `permissionType` | 匹配插件权限状态 |

自定义条件：

```javascript
filters: {
  custom: "my_custom_filter",
  arguments: {
    mode: "strict"
  }
}
```

### declaredFilters 兼容写法

```javascript
declaredFilters: [
  "event_message_type:group",
  "platform_adapter_type:onebot",
  "permission_type:send_message",
  "custom_filter:my_custom_filter"
]
```

兼容写法会编译为 `allOf`。同一注册上不能同时写 `declaredFilters` 和 `filters`。

## LLM 钩子

```javascript
hostApi.registerLlmHook({
  hook: "on_decorating_result",
  key: "my-plugin.llm-decorate",
  priority: 100,
  metadata: {},
  handler(payload) {
    const { result } = payload;
    result.appendText("\n\n由插件追加。");
  },
});
```

当前钩子阶段：

| hook | 触发时机 | payload |
|------|----------|---------|
| `on_waiting_llm_request` | LLM 请求排队时 | 扁平对象，含 `event` |
| `on_llm_request` | LLM 请求发出前 | `{ event, request }` |
| `on_llm_response` | LLM 返回后 | `{ event, response }` |
| `on_decorating_result` | 回复发送前 | `{ event, result }` |
| `after_message_sent` | 消息已发送 | `{ event, view }` |

### on_llm_request

```javascript
handler(payload) {
  const { request } = payload;
  request.appendSystemPrompt("额外指令");
  // request.replaceSystemPrompt("完全替换系统提示");
}
```

常见可读字段：

`requestId`、`conversationId`、`messageIds`、`llmInputSnapshot`、`availableProviderIds`、`availableModelIdsByProvider`、`selectedProviderId`、`selectedModelId`、`systemPrompt`、`messages`、`temperature`、`topP`、`maxTokens`、`streamingEnabled`、`metadata`。

### on_llm_response

```javascript
handler(payload) {
  const { response } = payload;
  hostApi.log("INFO", "LLM returned", {
    providerId: response.providerId,
    modelId: response.modelId
  });
}
```

常见字段：

`requestId`、`providerId`、`modelId`、`text`、`markdown`、`finishReason`、`metadata`、`usage`、`toolCalls`。

### on_decorating_result

```javascript
handler(payload) {
  const { result } = payload;
  result.appendText("\n-- 插件后缀");
  result.appendAttachment({ uri: "assets/decoration.png", mimeType: "image/png" });
  // result.replaceText("替换文本");
  // result.clearText();
  // result.replaceAttachments([]);
  // result.clearAttachments();
  // result.setShouldSend(false);
  // result.stop();
}
```

### after_message_sent

```javascript
handler(payload) {
  const { view } = payload;

  if (view.canSendFollowup && typeof view.sendFollowup === "function") {
    view.sendFollowup("补发文本", [
      { uri: "assets/extra.png", mimeType: "image/png" }
    ]);
  }
}
```

`view.canSendFollowup` 在 QQ 等外部平台下可能为 `true`，在应用内聊天下通常为 `false`。

## 生命周期钩子

```javascript
hostApi.onPluginLoaded({
  key: "my-plugin.loaded",
  handler() {
    hostApi.log("INFO", "插件已加载");
  },
});

hostApi.onPluginUnloaded({
  key: "my-plugin.unloaded",
  handler() {
    hostApi.log("INFO", "插件已卸载");
  },
});

hostApi.onPluginError({
  key: "my-plugin.error",
  handler(payload) {
    hostApi.log("ERROR", "插件出错", payload || {});
  },
});
```

完整写法：

```javascript
hostApi.registerLifecycleHandler({
  hook: "on_plugin_loaded",
  key: "my-plugin.loaded",
  priority: 100,
  metadata: {},
  handler() {}
});
```

生命周期钩子不接受 `filters` 或 `declaredFilters`。

## 工具注册

```javascript
hostApi.registerTool({
  name: "lookup",
  description: "查询一个值",
  inputSchema: {
    type: "object",
    properties: {
      query: { type: "string" }
    },
    required: ["query"]
  },
  handler: async (args) => {
    return {
      status: "success",
      text: `查询：${args.payload.query}`
    };
  }
});
```

也可以把 handler 作为第二个参数：

```javascript
hostApi.registerTool({
  name: "lookup",
  description: "查询一个值",
  inputSchema: { type: "object" }
}, async (args) => {
  return "ok";
});
```

插件工具名称不要使用宿主保留前缀：`mcp.`、`skill.`、`web.`、`active.`、`ctx.`、`context.`。

## 定时回调

权限：`schedule_manage`。如果定时回调内要发送消息、打开流或读取历史，还需要对应的 `send_message`、`message_stream` 或 `conversation_read` 等权限。

```javascript
hostApi.registerScheduledHandler({
  key: "daily-summary",
  cron: "0 9 * * *",
  metadata: {},
  handler: async (event) => {
    await hostApi.message.send({ text: "每日提醒" });
  }
});
```

一次性时间：

```javascript
hostApi.registerScheduledHandler({
  key: "run-once",
  runAt: Date.now() + 60_000,
  handler: async (event) => {
    await hostApi.message.send({ text: "一分钟到了" });
  }
});
```

约束：

- `cron` 与 `runAt` 必须二选一。
- 在消息事件上下文中注册时，`conversationId` / `platformAdapterType` 省略则默认绑定当前会话。
- 如显式传入目标会话，必须与当前事件会话一致。
- 启动阶段无当前会话时只能注册无显式 target 的 handler；后续能否触达会话取决于宿主授权的 schedule target。

定时事件字段：

| 字段 | 说明 |
|------|------|
| `pluginId` | 插件 ID |
| `handlerKey` | 注册 key |
| `jobId` | 宿主 Cron job ID |
| `conversationId` | 目标会话 |
| `platformAdapterType` | 平台类型 |
| `scheduledAtEpochMillis` | 计划触发时间 |
| `triggerSource` | `plugin_v2_schedule` |

## Agent

权限：`agent_run`。

```javascript
hostApi.registerAgent({
  key: "research-agent",
  systemPrompt: "你是一个研究助手。必要时调用工具。",
  tools: ["lookup"],
  model: {
    providerId: "provider-main",
    modelId: "model-main"
  },
  handler: async ({ input, agent }) => {
    return await agent.run(input);
  }
});
```

在命令中调用：

```javascript
hostApi.registerCommandHandler({
  key: "my-plugin.ask-agent",
  command: "ask",
  handler: async (event) => {
    const result = await hostApi.agent.run({
      key: "research-agent",
      input: event.remainingText || "请总结当前上下文",
      maxToolCalls: 8,
      maxDepth: 8,
      timeoutMs: 30000,
      maxTokens: 32768,
      maxCostMicros: 5000000
    });

    if (result.ok === false || !result.succeeded) {
      event.replyText(`Agent 失败：${result.error?.code || result.failureCode}`);
      return;
    }

    event.replyText(result.text);
  }
});
```

Agent 的 LLM / tool loop 由宿主运行，默认绕过插件 LLM hooks。`tools` 中应只列出当前插件注册的工具或宿主实际可用的工具来源。
