# 06 — 资源与附件

插件可以随包提供静态资源，也可以通过受控 URI 在消息中引用资源。不同发送入口支持的字段略有差异。

## 资源目录

```text
my-plugin/
├── runtime/
│   └── bootstrap.js
└── assets/
    ├── welcome.png
    └── sounds/
        └── ding.mp3
```

推荐把图片、音频、模板文件等静态资源放在 `assets/` 下。

## 命令回复附件

`event.replyResult()` 支持相对路径，宿主会解析到插件根目录：

```javascript
handler(event) {
  event.replyResult({
    text: "这是一张图片：",
    attachments: [
      {
        source: "assets/welcome.png",
        mimeType: "image/png",
        label: "欢迎图"
      }
    ]
  });
}
```

attachment 字段：

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `source` | string | 是 | 资源路径，优先级最高 |
| `uri` | string | 否 | `source` 的别名 |
| `assetPath` | string | 否 | `source` 的别名 |
| `path` | string | 否 | `source` 的别名 |
| `mimeType` | string | 否 | MIME 类型 |
| `label` | string | 否 | 显示标签 |
| `altText` | string | 否 | `label` 的别名 |
| `fileName` | string | 否 | `label` 的别名 |

`source` / `uri` / `assetPath` / `path` 按顺序取第一个非空值。

## hostApi.message.send 附件

`hostApi.message.send({ attachments })` 使用 `uri` 字段，并受安全 URI 限制：

```javascript
await hostApi.message.send({
  text: "资源：",
  attachments: [
    {
      uri: "plugin://package/assets/welcome.png",
      mimeType: "image/png"
    }
  ]
});
```

允许的媒体 URI：

| URI | 说明 |
|-----|------|
| `plugin://package/...` | 插件包内资源 |
| `plugin://workspace/...` | 插件私有 workspace 资源 |
| `content://com.elymbot.android.fileprovider/...` | 宿主 file provider 暴露的文件 |
| `https://...` | HTTPS 资源 |

不允许空路径、包含 `..` 的路径、普通绝对文件路径、任意 `content://`、`http://` 或 `base64:`。

## 富消息链

富消息链通过 `hostApi.message.send({ chain })` 发送，需要 `rich_message_send` 权限。

```javascript
await hostApi.message.send({
  chain: [
    { type: "text", text: "看图：" },
    {
      type: "image",
      uri: "plugin://package/assets/welcome.png",
      alt: "欢迎图",
      mimeType: "image/png"
    },
    { type: "mention", userId: "123456", label: "用户" },
    { type: "reply", messageId: "message-1" },
    {
      type: "card",
      title: "链接标题",
      text: "摘要",
      url: "https://example.com"
    }
  ]
});
```

支持的 segment：

| type | 字段 | 平台表现 |
|------|------|----------|
| `text` | `text` | 原样文本 |
| `image` | `uri`、`alt?`、`mimeType?` | App Chat 为附件；QQ 为图片附件 |
| `file` | `uri`、`name?`、`mimeType?` | App Chat 为附件；QQ 可能降级 |
| `mention` | `userId`、`label?` | QQ 尝试 `CQ:at`；其他平台降级为文本 |
| `reply` | `messageId` | QQ 尝试 `CQ:reply`；其他平台降级为文本 |
| `card` | `title`、`text?`、`url?` | 当前降级为文本 |

返回结果中的 `warnings` 会说明哪些 segment 发生了平台降级。

## LLM 钩子附件

`on_decorating_result` 阶段的 `result` 对象支持附件操作：

```javascript
hostApi.registerLlmHook({
  hook: "on_decorating_result",
  key: "my-plugin.add-image",
  priority: 100,
  handler(payload) {
    const result = payload && payload.result;
    if (!result) return;

    result.appendAttachment({
      uri: "assets/decoration.png",
      mimeType: "image/png"
    });
  },
});
```

方法：

| 方法 | 说明 |
|------|------|
| `result.appendAttachment({ uri, mimeType? })` | 追加附件 |
| `result.replaceAttachments([{ uri, mimeType? }])` | 替换附件列表 |
| `result.clearAttachments()` | 清空附件 |

LLM 钩子附件沿用当前 LLM pipeline 的附件规则；普通资源优先使用插件相对路径。

## 常见 MIME 类型

| 类型 | mimeType |
|------|----------|
| JPEG 图片 | `image/jpeg` |
| PNG 图片 | `image/png` |
| GIF 动图 | `image/gif` |
| WebP 图片 | `image/webp` |
| MP3 音频 | `audio/mpeg` |
| MP4 视频 | `video/mp4` |

## 不支持能力

- 当前不提供文本转图片 Host API。
- 当前不提供 HTML 渲染 Host API。
- 插件不能通过本地文件路径越权读取宿主或其他插件文件。
