# 01 — 快速开始

## 1. 创建插件目录

```text
my-plugin/
├── manifest.json
├── android-plugin.json
├── _conf_schema.json
├── runtime/
│   └── bootstrap.js
├── schemas/
│   └── settings-schema.json
└── assets/
```

只有 `manifest.json`、`android-plugin.json` 和 `runtime/bootstrap.js` 是必需文件。配置、设置 UI 和资源目录按需提供。

## 2. 最小 manifest.json

```json
{
  "pluginId": "com.yourname.myplugin",
  "version": "1.0.0",
  "protocolVersion": 2,
  "author": "Your Name",
  "title": "我的插件",
  "description": "一句话描述",
  "permissions": [],
  "minHostVersion": "0.4.0",
  "maxHostVersion": "",
  "sourceType": "LOCAL_FILE",
  "entrySummary": "提供 /ping 命令",
  "riskLevel": "LOW"
}
```

关键字段：

- `pluginId`：全局唯一，推荐反向域名风格。
- `protocolVersion`：固定为 `2`。
- `permissions`：必须存在。只做命令/日志/配置读取时可为空数组；调用受控 Host API 时必须声明对应权限。
- `minHostVersion`：建议从 `"0.4.0"` 起。

## 3. 最小 android-plugin.json

```json
{
  "protocolVersion": 2,
  "runtime": {
    "kind": "js_quickjs",
    "bootstrap": "runtime/bootstrap.js",
    "apiVersion": 1
  },
  "config": {
    "staticSchema": "",
    "settingsSchema": ""
  }
}
```

如需网络请求，必须在 `android-plugin.json` 中额外声明裸域名白名单：

```json
{
  "protocolVersion": 2,
  "runtime": {
    "kind": "js_quickjs",
    "bootstrap": "runtime/bootstrap.js",
    "apiVersion": 1
  },
  "config": {
    "staticSchema": "",
    "settingsSchema": ""
  },
  "network": {
    "allowedDomains": ["api.example.com"]
  }
}
```

`allowedDomains` 只能写裸域名，不包含协议、路径或端口。

## 4. 最小 bootstrap.js

```javascript
export default async function bootstrap(hostApi) {
  hostApi.log("INFO", "[my-plugin] loaded");

  hostApi.registerCommandHandler({
    key: "my-plugin.ping",
    command: "ping",
    aliases: [],
    groupPath: [],
    priority: 0,
    metadata: {},
    handler(event) {
      event.replyText("pong!");
    },
  });
}
```

要点：

1. 必须使用 `export default`。
2. 导出的函数必须是 `async function bootstrap(hostApi)`。
3. 所有注册都在 `bootstrap` 执行期间完成，不要延迟到定时器或异步后台任务中注册。
4. 不要使用 `activate(hostApi)`、`registerCommand(...)`、`onDecoratingResult(...)` 等旧式写法。

## 5. 导入与运行

1. 将整个插件目录打包或复制为 ElymBot 可导入的插件包。
2. 在 ElymBot 插件管理中导入或刷新。
3. 启用插件。
4. 在聊天中发送 `/ping`，应收到 `pong!`。

## 6. 带 Host API 权限的最小示例

如果插件要发送主动消息，需要声明 `send_message` 权限：

```json
{
  "permissionId": "send_message",
  "title": "发送消息",
  "description": "允许插件向当前会话发送宿主消息",
  "riskLevel": "MEDIUM",
  "required": true
}
```

然后在命令中调用：

```javascript
hostApi.registerCommandHandler({
  key: "my-plugin.say",
  command: "say",
  handler: async (event) => {
    const result = await hostApi.message.send({
      text: event.remainingText || "hello",
    });

    if (result && result.ok === false) {
      event.replyText(`发送失败：${result.error.code}`);
    }
  },
});
```

Host API 失败通常返回 `{ ok: false, error: { code, message, details } }`。插件应显式判断失败结果。
